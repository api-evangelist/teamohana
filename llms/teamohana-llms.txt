# TeamOhana

> TeamOhana is an HR-technology headcount management and planning platform that acts as a single source of truth for a company's people budget, connecting Finance, HR, and Talent Acquisition teams around real-time approved headcount. The TeamOhana Public API exposes SCIM 2.0 user provisioning plus Headcount, Discovery, and Scenario data for planning and reporting.

## API

- [TeamOhana Public API — reference / FAQ](https://api.teamohana.us/faq/index.html): SCIM 2.0 + Headcount/Discovery/Scenario REST API. Base URL https://api.teamohana.us/{domain}. Bearer-token auth (separate keys for SCIM vs Headcount). Rate limit 5 requests/second.
- [OpenAPI (raw)](https://raw.githubusercontent.com/api-evangelist/teamohana/refs/heads/main/openapi/teamohana-openapi-original.json)

## Endpoints

- SCIM: GET /{domain}/ServiceProviderConfig, GET/POST /{domain}/Users, GET/PUT/DELETE /{domain}/Users/{id}
- Headcount: GET/POST /{domain}/v1/headcount, POST /{domain}/v1/headcount/upload/pigment
- Discovery: GET /{domain}/v1/plans, GET /{domain}/v1/departments, GET /{domain}/v1/divisions
- Scenario: GET /{domain}/v1/scenarios, GET /{domain}/v1/scenarios/{id}/export
